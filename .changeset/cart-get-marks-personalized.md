`cartHandlers.get()` now marks the request's response as personalized on every call, so `applyResponseHeaders()` makes a page or React Router `.data` response that renders the cart private and uncacheable. Before, a loader that kept only the handler's `data` threw away its private cache headers, and a shared cache could serve one buyer's cart ID and key to other visitors. The handler marks the response before it fetches the cart, so a loader that streams the cart promise is covered too. The mark is unconditional because a page cached for a visitor with no cart carries `{cart: null}`, which tells `CartProvider` not to fetch `/api/cart`, so a buyer with a cart would get an empty cart. A `cart` cookie for an expired or completed cart still makes the response private. In Next.js, `proxy.ts` marks every page response personalized because `AppShell` reads the cart on every page. The Next.js references in the `hydrogen-cart-ui` and `hydrogen-request-handlers` skills show the call.
