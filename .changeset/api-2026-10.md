Use version `2026-10` of the Storefront API and Customer Account API. The [2026-10 release notes](https://shopify.dev/changelog/release-notes/2026-10) list everything that changed. The changes most likely to affect your code:

- Customer Account API: `CustomerAddressInput.territoryCode` and `CustomerAddress.territoryCode` are deprecated in favour of `countryCode`, which takes a two-letter `CountryCode` such as `US`. Hydrogen's generated types leave out deprecated input fields, so address mutations need to send `countryCode`.
- Customer Account API: `Customer.lastIncompleteCheckout` and the `Checkout` types are removed.
- Storefront API: cart line `discountAllocations` has a new `lineLevelOnly` argument. It defaults to `true`, which returns only line-level discounts; pass `lineLevelOnly: false` to include order-level discounts.
- Storefront API: `ShopPayPaymentRequestSession.paymentRequest` can now be `null`.
