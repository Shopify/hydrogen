Agentic Storefront E2E

Each test is a goal written in shopper language. An AI agent works through any storefront to reach it, using only screenshots, mouse and keyboard. Shopify's own data decides the outcome.

Outcomes

The agent's claim (done, blocked or gave up) is combined with what Shopify reports. A storefront is only blamed when Shopify's data is wrong.

PASS

Shopify's data matches the goal, and the agent only used the store's own UI.

PASSfriction

It passed, but the agent's notes show it had to correct or work around something. The UX notes say what.

FAIL

The agent said it was done, but Shopify's data is wrong, or checkout never happened. The UI misled the shopper.

BLOCKED

The agent reported that the store stopped it, Shopify agrees nothing was completed, and the agent explains what it saw.

INCONCLUSIVE

It ran out of steps or time, took a shortcut such as typing a URL, or Shopify's data couldn't be read. This says nothing about the store.

STALE

Replays only: a recorded step no longer works because the UI changed. The agent regenerates the spec, and the diff shows what changed.
