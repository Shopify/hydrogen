# Documentation Dependency Map

## Next.js Template Sync

- `examples/nextjs/**` is the source app for `templates/nextjs/**` feature and styling syncs.
- `templates/nextjs/**` must stay standalone: no `@shared/*`, no `workspace:*`, no `catalog:`, and no monorepo-only dev scripts.
- `templates/nextjs/.agents/skills/**` is generated by `pnpm sync:template-skills` from `packages/hydrogen/skills/**`. Do not edit copied skill files directly.
- `packages/hydrogen/skills/**` is the source for template-shipped agent docs. Update these before running `pnpm sync:template-skills`.
- `skills/create-vercel-template/SKILL.md` documents the workflow for recreating `templates/nextjs` from `examples/nextjs`. Keep it aligned with `templates/nextjs/package.json`, env names, layout paths, and caching strategy.
- `README.md` includes public setup examples for Hydrogen skills. Keep its path and env examples aligned with `templates/nextjs` when the template structure changes.

## Validation Links

- After changing `packages/hydrogen/skills/**`, run `pnpm sync:template-skills` and `pnpm sync:template-skills:check`.
- After changing `templates/nextjs/**`, run the template lint, typecheck, build, and local smoke test.
